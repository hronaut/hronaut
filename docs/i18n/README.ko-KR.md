**코딩 에이전트에게는 전용 브라우저를. 내 브라우저는 그대로.**

Hronaut는 코딩 에이전트를 위한 눈에 보이는 데스크톱 브라우저로, 프로젝트마다 별도의 워크스페이스를 둡니다. 평소 쓰는 Chrome은 건드리지 않으며, 언제든 일시 중지하고 직접 이어받을 수 있습니다. Codex, Claude Code, Cursor 같은 코딩 에이전트에게 로그인된 웹 앱을 점검하게 하는 개발자와 에이전시를 위한 것입니다.

**[다운로드](https://hronaut.dev/download)** · **[설정 가이드](https://hronaut.dev/setup)** · **[가격](https://hronaut.dev/#pricing)**

Windows, macOS, Linux 지원. 10일 무료 체험은 카드가 필요 없고 요금이 청구되지 않습니다. 이후 지정 사용자 1명당 월 4달러 또는 연 24달러입니다.

- **평소 쓰는 Chrome은 건드리지 않습니다.** 에이전트는 메일과 은행이 있는 Chrome이 아니라 Hronaut에서 일합니다. Hronaut에서 로그인한 것은 사용할 수 있습니다.
- **프로젝트나 클라이언트마다 워크스페이스 하나.** 각자 쿠키와 로그인을 따로 가지며, 채팅이 끝나도 열려 있습니다.
- **지켜보고, 멈추고, 이어받기.** 로그인이나 2FA는 직접 하고, 그다음 탭을 다시 넘기세요.

## 세 단계로 시작하기

1. Windows, macOS, Linux용 [Hronaut를 다운로드](https://hronaut.dev/download)하고 실행합니다.
2. Hronaut 홈에서 코딩 에이전트를 고르고 생성된 설정을 복사하거나, [설정 가이드](https://hronaut.dev/setup)를 따릅니다.
3. 연결된 에이전트에게 이렇게 요청합니다: `Using Hronaut, create a new isolated workspace named “Hronaut first run”, open https://example.com, take a semantic snapshot, and tell me the page heading. Use only that task workspace.`

실행 과정은 Hronaut에 그대로 보이고, 분리된 워크스페이스가 만들어지며, 에이전트와의 대화가 끝나도 남아 있습니다.
