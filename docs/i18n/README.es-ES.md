**Dale a tu agente de código su propio navegador. Quédate con el tuyo.**

Hronaut es un navegador de escritorio visible para agentes de código, con un espacio de trabajo separado para cada proyecto. Tu Chrome de cada día queda fuera, y puedes pausar y tomar el control en cualquier momento. Es para desarrolladores y agencias que dejan que Codex, Claude Code, Cursor u otro agente de código revise aplicaciones web con sesión iniciada.

**[Descargar](https://hronaut.dev/download)** · **[Guía de configuración](https://hronaut.dev/setup)** · **[Precios](https://hronaut.dev/#pricing)**

Para Windows, macOS y Linux. Prueba gratis de 10 días: sin tarjeta y nunca te cobra. Después, 4 $ al mes o 24 $ al año por usuario nombrado.

- **Tu Chrome de cada día queda fuera.** Los agentes trabajan en Hronaut, no en el Chrome con tu correo y tu banco. Pueden usar las sesiones que inicies en Hronaut.
- **Un espacio de trabajo por proyecto o cliente.** Cada uno guarda sus propias cookies y sesiones, y sigue abierto cuando termina el chat.
- **Mira, pausa, toma el control.** Haz tú el inicio de sesión o la 2FA y luego devuelve la pestaña.

## Empieza en tres pasos

1. [Descarga Hronaut](https://hronaut.dev/download) para Windows, macOS o Linux y ábrelo.
2. En el Inicio de Hronaut, elige tu agente de código y copia la configuración generada, o sigue la [guía de configuración](https://hronaut.dev/setup).
3. Pide al agente conectado: `Using Hronaut, create a new isolated workspace named “Hronaut first run”, open https://example.com, take a semantic snapshot, and tell me the page heading. Use only that task workspace.`

La prueba queda visible en Hronaut, crea un espacio de trabajo aislado y sigue disponible cuando termina la conversación con el agente.
