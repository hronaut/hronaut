**給你的程式代理一個它自己的瀏覽器。你的瀏覽器留給你自己。**

Hronaut 是一款為程式代理打造的可見桌面瀏覽器，每個專案都有獨立的工作區。你日常使用的 Chrome 不會受到影響，你也可以隨時暫停並接手。它適合讓 Codex、Claude Code、Cursor 或其他程式代理檢查已登入 Web 應用程式的開發者與代理商。

**[下載](https://hronaut.dev/download)** · **[設定指南](https://hronaut.dev/setup)** · **[價格](https://hronaut.dev/#pricing)**

支援 Windows、macOS 和 Linux。10 天免費試用：不需信用卡，也絕不會收費。之後每位指定使用者每月 4 美元或每年 24 美元。

- **日常使用的 Chrome 不受影響。** 代理在 Hronaut 裡工作，而不是在裝著你的電子郵件和網路銀行的 Chrome 裡。它們可以使用你在 Hronaut 中登入的帳號。
- **每個專案或客戶一個工作區。** 每個工作區都有自己的 Cookie 和登入狀態，對話結束後仍會保留。
- **觀看、暫停、接手。** 登入或 2FA 由你親自完成，然後把分頁交還給代理。

## 三步驟開始

1. [下載 Hronaut](https://hronaut.dev/download)（Windows、macOS 或 Linux）並啟動。
2. 在 Hronaut 首頁選擇你的程式代理並複製產生的設定，或參考[設定指南](https://hronaut.dev/setup)。
3. 對已連線的代理說： `Using Hronaut, create a new isolated workspace named “Hronaut first run”, open https://example.com, take a semantic snapshot, and tell me the page heading. Use only that task workspace.`

執行過程在 Hronaut 中清楚可見，會建立一個獨立的工作區，並在與代理的對話結束後仍然保留。
