**Donnez à votre agent de code son propre navigateur. Gardez le vôtre.**

Hronaut est un navigateur de bureau visible pour les agents de code, avec un espace de travail séparé pour chaque projet. Votre Chrome de tous les jours reste à l’écart, et vous pouvez mettre en pause et reprendre la main à tout moment. Il s’adresse aux développeurs et aux agences qui laissent Codex, Claude Code, Cursor ou un autre agent de code vérifier des applications web connectées.

**[Télécharger](https://hronaut.dev/download)** · **[Guide d’installation](https://hronaut.dev/setup)** · **[Tarifs](https://hronaut.dev/#pricing)**

Pour Windows, macOS et Linux. Essai gratuit de 10 jours : sans carte, et rien n’est jamais prélevé. Ensuite 4 $ par mois ou 24 $ par an et par utilisateur nommé.

- **Votre Chrome de tous les jours reste à l’écart.** Les agents travaillent dans Hronaut, pas dans le Chrome qui contient votre messagerie et votre banque. Ils peuvent utiliser les connexions que vous faites dans Hronaut.
- **Un espace de travail par projet ou par client.** Chacun garde ses propres cookies et connexions, et reste ouvert après la fin de la conversation.
- **Regardez, mettez en pause, reprenez la main.** Faites vous-même la connexion ou la 2FA, puis rendez l’onglet.

## Démarrer en trois étapes

1. [Téléchargez Hronaut](https://hronaut.dev/download) pour Windows, macOS ou Linux et lancez-le.
2. Sur l’Accueil de Hronaut, choisissez votre agent de code et copiez la configuration générée, ou suivez le [guide d’installation](https://hronaut.dev/setup).
3. Demandez à l’agent connecté : `Using Hronaut, create a new isolated workspace named “Hronaut first run”, open https://example.com, take a semantic snapshot, and tell me the page heading. Use only that task workspace.`

L’essai reste visible dans Hronaut, crée un espace de travail isolé et reste disponible après la fin de la conversation avec l’agent.
