**Дайте своєму агенту для коду власний браузер. Залиште свій собі.**

Hronaut — видимий настільний браузер для агентів, що пишуть код, з окремим робочим простором для кожного проєкту. Ваш щоденний Chrome лишається осторонь, і ви будь-коли можете поставити агента на паузу й узяти керування на себе. Він для розробників і агенцій, які доручають Codex, Claude Code, Cursor чи іншому агенту перевіряти вебзастосунки, де потрібен вхід в акаунт.

**[Завантажити](https://hronaut.dev/download)** · **[Налаштування](https://hronaut.dev/setup)** · **[Ціни](https://hronaut.dev/#pricing)**

Для Windows, macOS і Linux. 10 днів безкоштовно: без картки, і нічого не списується. Далі 4 $ на місяць або 24 $ на рік за іменного користувача.

- **Ваш щоденний Chrome лишається осторонь.** Агенти працюють у Hronaut, а не в Chrome з вашою поштою та банком. Їм доступні акаунти, у які ви входите в Hronaut.
- **Один робочий простір на проєкт чи клієнта.** У кожного свої cookie та входи, і він лишається відкритим після завершення чату.
- **Дивіться, ставте на паузу, беріть керування.** Увійдіть або пройдіть 2FA самі, а потім поверніть вкладку агенту.

## Почати за три кроки

1. [Завантажте Hronaut](https://hronaut.dev/download) для Windows, macOS або Linux і запустіть.
2. На головній Hronaut виберіть свого агента й скопіюйте готове налаштування або відкрийте [посібник із налаштування](https://hronaut.dev/setup).
3. Попросіть підключеного агента: `Using Hronaut, create a new isolated workspace named “Hronaut first run”, open https://example.com, take a semantic snapshot, and tell me the page heading. Use only that task workspace.`

Запуск видно в Hronaut, він створює окремий робочий простір і лишається доступним після завершення розмови з агентом.
