# Hronaut

**अपने कोडिंग एजेंट को उसका अपना ब्राउज़र दें। अपना ब्राउज़र अपने पास रखें।**

Hronaut कोडिंग एजेंटों के लिए एक दिखने वाला डेस्कटॉप ब्राउज़र है, जिसमें हर प्रोजेक्ट का अलग वर्कस्पेस होता है। आपका रोज़ का Chrome इससे बाहर रहता है, और आप कभी भी रोक सकते हैं और नियंत्रण ले सकते हैं। यह उन डेवलपरों और एजेंसियों के लिए है जो Codex, Claude Code, Cursor या किसी दूसरे कोडिंग एजेंट से साइन-इन वाले वेब ऐप जँचवाते हैं।

**[डाउनलोड](https://hronaut.dev/download)** · **[सेटअप गाइड](https://hronaut.dev/setup)** · **[कीमत](https://hronaut.dev/#pricing)**

Windows, macOS और Linux के लिए। 10 दिन का मुफ़्त ट्रायल: कार्ड नहीं चाहिए और कभी पैसे नहीं कटते। उसके बाद हर नामित उपयोगकर्ता के लिए $4 प्रति माह या $24 प्रति वर्ष।

- **आपका रोज़ का Chrome बाहर रहता है।** एजेंट Hronaut में काम करते हैं, उस Chrome में नहीं जिसमें आपका ईमेल और बैंक है। वे वही इस्तेमाल कर सकते हैं जिसमें आप Hronaut में साइन इन करते हैं।
- **हर प्रोजेक्ट या क्लाइंट के लिए एक वर्कस्पेस।** हर एक की अपनी कुकी और साइन-इन होते हैं, और चैट खत्म होने के बाद भी वह खुला रहता है।
- **देखें, रोकें, नियंत्रण लें।** लॉगिन या 2FA खुद करें, फिर टैब वापस सौंप दें।

## तीन चरणों में शुरू करें

1. Windows, macOS या Linux के लिए [Hronaut डाउनलोड करें](https://hronaut.dev/download) और उसे चलाएँ।
2. Hronaut के Home पर अपना कोडिंग एजेंट चुनें और बना हुआ सेटअप कॉपी करें, या [सेटअप गाइड](https://hronaut.dev/setup) देखें।
3. जुड़े हुए एजेंट से कहें: `Using Hronaut, create a new isolated workspace named “Hronaut first run”, open https://example.com, take a semantic snapshot, and tell me the page heading. Use only that task workspace.`

यह रन Hronaut में दिखता रहता है, एक अलग वर्कस्पेस बनाता है, और एजेंट से बातचीत खत्म होने के बाद भी उपलब्ध रहता है।
