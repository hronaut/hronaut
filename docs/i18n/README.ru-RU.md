**Дайте своему агенту для кода свой браузер. Оставьте свой себе.**

Hronaut — видимый настольный браузер для агентов, которые пишут код, с отдельным рабочим пространством для каждого проекта. Ваш повседневный Chrome остаётся в стороне, и вы в любой момент можете поставить агента на паузу и взять управление на себя. Он для разработчиков и агентств, которые поручают Codex, Claude Code, Cursor или другому агенту проверять веб-приложения, где нужен вход в аккаунт.

**[Скачать](https://hronaut.dev/download)** · **[Настройка](https://hronaut.dev/setup)** · **[Цены](https://hronaut.dev/#pricing)**

Для Windows, macOS и Linux. 10 дней бесплатно: без карты, и ничего не списывается. Дальше 4 $ в месяц или 24 $ в год за именного пользователя.

- **Ваш повседневный Chrome остаётся в стороне.** Агенты работают в Hronaut, а не в Chrome с вашей почтой и банком. Им доступны аккаунты, в которые вы входите в Hronaut.
- **Одно рабочее пространство на проект или клиента.** У каждого свои cookie и входы, и оно остаётся открытым после конца чата.
- **Смотрите, ставьте на паузу, берите управление.** Войдите или пройдите 2FA сами, а потом верните вкладку агенту.

## Начать за три шага

1. [Скачайте Hronaut](https://hronaut.dev/download) для Windows, macOS или Linux и запустите.
2. На главной Hronaut выберите своего агента и скопируйте готовую настройку или откройте [руководство по настройке](https://hronaut.dev/setup).
3. Попросите подключённого агента: `Using Hronaut, create a new isolated workspace named “Hronaut first run”, open https://example.com, take a semantic snapshot, and tell me the page heading. Use only that task workspace.`

Запуск виден в Hronaut, создаёт отдельное рабочее пространство и остаётся доступным после окончания разговора с агентом.
