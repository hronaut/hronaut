**Beri agen coding Anda browsernya sendiri. Simpan browser Anda.**

Hronaut adalah browser desktop yang terlihat untuk agen coding, dengan workspace terpisah untuk setiap proyek. Chrome sehari-hari Anda tetap di luar, dan Anda bisa menjeda dan mengambil alih kapan saja. Ini untuk developer dan agensi yang membiarkan Codex, Claude Code, Cursor, atau agen coding lain memeriksa aplikasi web yang sudah login.

**[Unduh](https://hronaut.dev/download)** · **[Panduan penyiapan](https://hronaut.dev/setup)** · **[Harga](https://hronaut.dev/#pricing)**

Untuk Windows, macOS, dan Linux. Uji coba gratis 10 hari: tanpa kartu dan tidak pernah menagih Anda. Setelah itu $4 per bulan atau $24 per tahun per pengguna bernama.

- **Chrome sehari-hari Anda tetap di luar.** Agen bekerja di Hronaut, bukan di Chrome yang berisi email dan bank Anda. Mereka bisa memakai akun yang Anda login-kan di Hronaut.
- **Satu workspace per proyek atau klien.** Masing-masing punya cookie dan login sendiri, dan tetap terbuka setelah chat berakhir.
- **Lihat, jeda, ambil alih.** Lakukan login atau 2FA sendiri, lalu kembalikan tab-nya.

## Mulai dalam tiga langkah

1. [Unduh Hronaut](https://hronaut.dev/download) untuk Windows, macOS, atau Linux, lalu jalankan.
2. Di Home Hronaut, pilih agen coding Anda dan salin penyiapan yang dibuat, atau ikuti [panduan penyiapan](https://hronaut.dev/setup).
3. Minta agen yang terhubung: `Using Hronaut, create a new isolated workspace named “Hronaut first run”, open https://example.com, take a semantic snapshot, and tell me the page heading. Use only that task workspace.`

Hasilnya tetap terlihat di Hronaut, membuat workspace terisolasi, dan tetap tersedia setelah percakapan dengan agen berakhir.
