**给你的编程代理一个它自己的浏览器。你的浏览器留给你自己。**

Hronaut 是一款面向编程代理的可见桌面浏览器，每个项目都有独立的工作区。你日常用的 Chrome 不受影响，你也可以随时暂停并接管。它适合让 Codex、Claude Code、Cursor 或其他编程代理检查已登录 Web 应用的开发者和代理公司。

**[下载](https://hronaut.dev/download)** · **[设置指南](https://hronaut.dev/setup)** · **[价格](https://hronaut.dev/#pricing)**

支持 Windows、macOS 和 Linux。10 天免费试用：无需绑卡，也绝不会扣费。之后每位指定用户每月 4 美元或每年 24 美元。

- **日常用的 Chrome 不受影响。** 代理在 Hronaut 里工作，而不是在装着你的邮箱和网银的 Chrome 里。它们可以使用你在 Hronaut 中登录的账号。
- **每个项目或客户一个工作区。** 每个工作区都有自己的 Cookie 和登录状态，对话结束后依然保留。
- **观看、暂停、接管。** 登录或 2FA 由你亲自完成，然后把标签页交还给代理。

## 三步开始

1. [下载 Hronaut](https://hronaut.dev/download)（Windows、macOS 或 Linux）并启动。
2. 在 Hronaut 主页选择你的编程代理并复制生成的设置，或参照[设置指南](https://hronaut.dev/setup)。
3. 对已连接的代理说： `Using Hronaut, create a new isolated workspace named “Hronaut first run”, open https://example.com, take a semantic snapshot, and tell me the page heading. Use only that task workspace.`

运行过程在 Hronaut 中清晰可见，会创建一个独立的工作区，并且在与代理的对话结束后依然保留。
