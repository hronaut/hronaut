**コーディングエージェントには専用のブラウザを。あなたのブラウザはあなたのままに。**

Hronaut は、コーディングエージェントのための目に見えるデスクトップブラウザで、プロジェクトごとに別のワークスペースを持ちます。普段使いの Chrome には触れず、いつでも一時停止して操作を引き継げます。Codex、Claude Code、Cursor などのコーディングエージェントに、サインイン済みの Web アプリを確認させる開発者やエージェンシーのためのものです。

**[ダウンロード](https://hronaut.dev/download)** · **[セットアップガイド](https://hronaut.dev/setup)** · **[料金](https://hronaut.dev/#pricing)**

Windows、macOS、Linux に対応。10 日間の無料トライアルはカード不要で、料金が発生することはありません。その後は指名ユーザー 1 人あたり月 4 ドルまたは年 24 ドルです。

- **普段使いの Chrome には触れません。** エージェントが作業するのは Hronaut の中で、メールや銀行が入った Chrome ではありません。Hronaut でサインインしたものは使えます。
- **プロジェクトやクライアントごとに 1 つのワークスペース。** それぞれが独自の Cookie とサインインを持ち、チャットが終わっても開いたままです。
- **見る、止める、引き継ぐ。** ログインや 2FA は自分で行い、そのあとタブを戻します。

## 3 ステップで始める

1. Windows、macOS、Linux 用の [Hronaut をダウンロード](https://hronaut.dev/download)して起動します。
2. Hronaut のホームでコーディングエージェントを選び、生成されたセットアップをコピーするか、[セットアップガイド](https://hronaut.dev/setup)に従います。
3. 接続したエージェントにこう頼みます: `Using Hronaut, create a new isolated workspace named “Hronaut first run”, open https://example.com, take a semantic snapshot, and tell me the page heading. Use only that task workspace.`

実行の様子は Hronaut に表示されたままで、分離されたワークスペースが作られ、エージェントとの会話が終わっても残ります。
